InfraForge

Local-First Infrastructure Automation

InfraForge is a local-first infrastructure automation and DevSecOps platform designed for engineers who want control, safety, and transparency — without SaaS lock-in.

🚀 Public Release: January 26, 2026

Status: v1.0.0 (Pre-release)

Platform Support

Linux only — Debian & CentOS family

Tested on Debian, Ubuntu, RHEL, CentOS, Rocky Linux, and AlmaLinux.

What InfraForge Does

Template Generation

Terraform, Docker, Helm, Jenkins, Security, and GitOps templates.

Validation & Safety

Configuration checks, placeholder validation, and pre-deployment safety gates.

Blueprint & Planning

Dry-run workflows to preview changes before execution.

Controlled Execution

No automatic deployment. Every action requires explicit user confirmation.

Quickstart

Linux only (Debian & CentOS family).

# Initialize a project
infraforge init

# Generate templates
infraforge gen terraform

# Validate configuration
infraforge check

# Preview changes
infraforge blueprint

No deployment happens without explicit confirmation.
